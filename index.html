Oriel repository

The Kodi install source for Oriel. The repository add-on installs and updates Oriel and its dependencies, Oriel framework and Oriel WebKit, from their latest GitHub releases.

Oriel targets Amlogic devices with a Mali GPU running CoreELEC 22 (Kodi 22, 64-bit). It is highly experimental and provided without support. Use it at your own risk.

Installation

  1. In Kodi, enable Settings → System → Add-ons → Unknown sources.
  2. Go to Settings → File manager → Add source, enter https://gr3ee3n.github.io/oriel-repository/ and name it Oriel.
  3. Go to Add-ons → Install from zip file → Oriel and select repository.oriel.zip.
  4. Go to Add-ons → Install from repository → Oriel repository → Video add-ons and select Oriel.
